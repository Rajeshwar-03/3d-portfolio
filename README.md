## Run
1. Extract the ZIP.
2. Open the folder in VS Code.
3. Install/use the Live Server extension.
4. Right-click `index.html` → **Open with Live Server**.

Do not double-click `index.html` because ES modules and browser security can block local module loading.

## Replace links
Open `index.html` and replace the `#` GitHub/LinkedIn links with your real profile URLs.

## Replace project visuals
The current project images are polished SVG preview graphics. If you have real screenshots of your projects, replace:
- `assets/images/grocery-ai.svg`
- `assets/images/healthcare-blockchain.svg`
- `assets/images/portfolio-3d.svg`

with your own images and update the filenames in `index.html`.
